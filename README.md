# 🍽️ رستوران چاشنی — Chashni Restaurant

وب‌سایت حرفه‌ای، مدرن و کاملاً ریسپانسیو برای **رستوران چاشنی**؛ مناسب برای نمونه‌کار (پورتفولیو)، رزومه و گیت‌هاب. کل سایت **فارسی و راست‌چین (RTL)** است و فقط با **HTML5 ،CSS3 و جاوااسکریپت خالص (Vanilla JS)** ساخته شده — بدون هیچ فریمورکی.

```

│   └── style.css         # استایل کامل سایت (متغیرها، گرید، ریسپانسیو)

│   ├── main.js           # نوبار، همبرگری، اسکرول، انیمیشن، بازگشت‌به‌بالا
│   ├── menu.js           # دیتای غذاها + رندر + فیلتر دسته‌بندی
```

## 🚀 اجرا

بدون بیلد و بدون نصب — کافی است یکی از روش‌ها:

**روش ۱ — باز کردن مستقیم:**
```bash
# فقط فایل را در مرورگر باز کنید
index.html
```

**روش ۲ — سرور لوکال (پیشنهادی):**
```bash
# با پایتون
python -m http.server 8000
# سپس باز کنید:
# http://localhost:8000/index.html

# یا با VS Code افزونه Live Server روی index.html
```

## 📌 نکات فنی

- اعداد و قیمت‌ها با `toLocaleString("fa-IR")` فارسی نمایش داده می‌شوند.
- دیتای غذاها در `js/menu.js` به‌صورت آرایه متمرکز است؛ صفحه خانه، منو و جزئیات از همان دیتا تغذیه می‌شوند.
- جزئیات غذا با کوئری‌پارامتر کار می‌کند: `food-details.html?id=3`
- دسترسی‌پذیری پایه: `aria-label`، `role`، `alt` تصاویر و HTML معنایی رعایت شده.
- بدون خطای کنسول؛ لینک‌های ناوبری همگی واقعی و سالم‌اند.
